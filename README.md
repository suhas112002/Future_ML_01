## AI-Powered Sales Forecasting Dashboard

## 📊 Project Overview
This project predicts future retail sales using historical data and time-series forecasting (Prophet).
Insights are visualized using an interactive Power BI dashboard.

## 🛠 Tools Used
- Python (Pandas, Prophet)
- Jupyter Notebook
- Power BI
- GitHub

## 📁 Files
- sales_forecast_output.csv – Forecast results
- Dashboard.pbix – Power BI dashboard
- dashboard_preview.png – Dashboard preview
- Snaphots-1,2,3,4,5

## 📈 Features
- Actual vs Forecast Sales
- KPI Cards
- Sales by Store / Category
- Year & Month slicers
